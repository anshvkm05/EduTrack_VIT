Coaching Institute Management System
EduTrack VIT

EduTrack VIT is a full-stack web application built with Flask and SQLite3 to streamline the daily operations of coaching institutes — from student enrollment and batch scheduling to fee collection, attendance tracking, and PDF reporting. It replaces Excel sheets and WhatsApp groups with a single, clean admin interface.

Core Features
🔐
Secure Admin Login
Session-based authentication with Flask-Login and Werkzeug password hashing. No student can access the system.
📊
Live Dashboard
Real-time stats with Chart.js visualisations — enrollment by course (doughnut) and monthly fee trend (bar chart).
👨‍🎓
Student Management
Full CRUD — enroll, edit, deactivate students. Search by name, email, or phone. Filter by status.
🏫
Batch Scheduling
Organise students into batches (Morning / Evening / Weekend) per course with time-slot labels.
💳
Fee Ledger
Log monthly payments, filter by month, and see total collections at a glance. No pending slip goes untracked.
📅
Attendance Tracking
Mark per-student, per-batch, per-day attendance with toggle switches. History is preserved and revisitable.
📄
PDF Reports
Generate a professional student report card (profile + fee history) as a downloadable PDF using fpdf2.
🌙
Dark Mode UI
Premium dark-mode design system with sidebar navigation, glassmorphism cards, and smooth micro-animations.
📱
Responsive Layout
Collapses gracefully on tablet and mobile — sidebar shrinks to icon-only, grids stack vertically.
